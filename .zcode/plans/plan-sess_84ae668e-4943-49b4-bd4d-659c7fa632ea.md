# 侧栏收起（图标栏 + 悬停气泡）实施计划

## Context

用户希望左侧菜单栏支持缩小。已确认两个决策：
- **形态**：收起为约 68px 纯图标栏，悬停菜单项浮出名称气泡，内容区实时变宽；状态存 localStorage 保持。
- **流程**：按 AGENTS.md 钦定两阶段——先改 `design/prototype/` 原型 → 用户浏览器审阅确认 → 再同步 React 前端。

现状：侧栏在 `frontend/src/AppShell.tsx:76-122`（brand → nav → sidebar-user），桌面网格列 232px 定义在 `frontend/src/index.css:63` 与 `design/prototype/components.css:7-9`；原型侧栏标记内联复制在 9 个 HTML 页里，共享交互在 `app.js`（IIFE，末尾可加新节）；<768px 侧栏整体隐藏（不受影响）；无现成 tooltip 组件。

## 关键设计规格

- 收起宽度 **68px**（侧栏内边距 12px×2 → 内容 44px，17px 图标居中）。
- 切换按钮 `.sidebar-collapse` 放侧栏最底部（用户块下方）：展开态 = ChevronsLeft 图标 + 「收起侧栏」文字（弱化色，样式同导航项）；收起态 = 图标旋转 180° 居中，带气泡「展开侧栏」。
- 收起态处理：`.brand-text`/`.user-name`/`.user-role`/退出按钮 `display:none`，头像居中；`.nav-label` 变成 1px 细分隔线；`.nav a` 用 `font-size:0 + justify-content:center`（图标有显式宽高不受影响）→ **原型 9 页无需改动任何 HTML 标记**。
- 气泡：通用规则 `.app.rail [data-tip]::after`，黑色圆角气泡出现在侧栏右侧，hover/focus-visible 显示，纯 CSS。原型里由 app.js 给每个 `.nav a` 注入 `data-tip`（取链接文字）。
- ⚠️ `.sidebar` 的 `overflow-y:auto` 会裁剪气泡 → 收起态加 `.app.rail .sidebar { overflow: visible }`（收起态内容紧凑，不会超高）。
- 宽度过渡动画 `grid-template-columns .25s`（现代浏览器可动画；`prefers-reduced-motion: reduce` 下禁用）。
- 平台管理员的酒店切换器（仅 React 端有，原型无）：收起后 select 隐藏，换成一个 Building2 图标按钮（data-tip「切换酒店」），点击恢复展开。
- localStorage key：`pms_rail`（'1'/'0'），前端读写沿用 `auth.tsx` 的 lazy useState + try/catch 模式。
- 移动端 <768px 侧栏 `display:none`，收起态无副作用；切换按钮在侧栏内也一并隐藏。

## 阶段一：原型（审阅门）

**改 `design/prototype/components.css`**（在侧栏小节后追加，不动既有规则）：
```css
.sidebar-collapse { /* 弱化色按钮，样式同 .nav a */ }
.app { transition: grid-template-columns .25s var(--ease); }  /* reduce 下禁用 */
.app.rail { grid-template-columns: 68px minmax(0,1fr); }
.app.rail .sidebar { overflow: visible; }
.app.rail .brand { justify-content: center; padding: 4px 0 14px; }
.app.rail .brand-text, .app.rail .user-name, .app.rail .user-role { display: none; }
.app.rail .sidebar-user { justify-content: center; padding: 6px; }
.app.rail .nav-label { font-size: 0; height: 1px; padding: 0; margin: 10px 6px 4px; background: var(--hairline-soft); }
.app.rail .nav a { font-size: 0; gap: 0; justify-content: center; padding: 9px 0; position: relative; }
.app.rail .sidebar-collapse { justify-content: center; }
.app.rail .sidebar-collapse svg { transform: rotate(180deg); }
.app.rail .sidebar-collapse span { display: none; }
.app.rail [data-tip] { position: relative; }
.app.rail [data-tip]::after { /* 黑气泡 attr(data-tip)，left:calc(100%+12px)，hover/focus-visible 显示 */ }
```

**改 `design/prototype/app.js`**（末尾新节，仅当 `.app`+`.sidebar` 存在时执行——index/login/mobile 页不受影响）：
1. 读 `localStorage['pms_rail']`，为 '1' 时给 `.app` 加 `rail` class（在首帧前执行，避免闪动）。
2. 给每个 `.nav a` 注入 `data-tip`（取 `textContent.trim()`）。
3. 注入 `.sidebar-collapse` 按钮（内联 ChevronsLeft SVG + `<span>收起侧栏</span>`，aria-expanded 随状态）到 `.sidebar` 末尾。
4. 点击切换 `rail` class 并写回 localStorage。

**验证**：`python3 -m http.server 4321 --directory design/prototype`，无头 Chrome 截图（遵守 AGENTS.md：最小宽 500px、每实例独立 `--user-data-dir`）——dashboard 展开态/收起态 1440px + 收起态 500px（确认移动端底部 Tab 不受影响），存入 `design/prototype/screenshots/`；刷新验证 localStorage 持久化。

**⏸ 审阅检查点**：交付 [http://localhost:4321/dashboard.html](http://localhost:4321/dashboard.html)（及其它页面）给用户在浏览器审阅，**确认通过后才进入阶段二**。

## 阶段二：React 前端（用户确认原型后）

1. **`frontend/src/index.css`**：把阶段一新增的 CSS 1:1 同步到外壳小节（`.app/.sidebar` 定义在 63–68 行附近）。
2. **`frontend/src/AppShell.tsx`**：
   - 新增 `rail` 状态：`useState(() => localStorage.getItem('pms_rail') === '1')`（try/catch 同 auth.tsx 模式）；toggle 函数持久化。
   - `<div className="app">` 按状态附加 `rail` class。
   - `NavLink` 增加 `data-tip={it.label}` 与 `aria-label`。
   - `.sidebar-user` 之后加 `.sidebar-collapse` 按钮（lucide `ChevronsLeft`，点击 toggle）。
   - 平台管理员酒店切换器（85–95 行）：`rail` 时渲染 Building2 图标按钮（data-tip「切换酒店」，点击展开侧栏），否则渲染原 select；头像加 `data-tip={user?.name}`。
3. **验证**：`npx tsc --noEmit`；起后端+前端，员工 `zhouqi` 与平台管理员 `admin` 两账号截图（1440px 展开态/收起态 + 500px 移动端），存 `screenshots/`；验证刷新持久化、气泡显示、切换器收起行为。后端无改动，无需 pytest。
